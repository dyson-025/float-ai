# Development Guide

This guide explains how to set up Float AI for local development.

## Prerequisites

The following tools will be required:

- Git
- Node.js
- npm
- Python
- Rust
- Tauri prerequisites for the target operating system
- PostgreSQL (when database functionality is introduced)

Exact versions will be documented once the initial project setup is complete.
