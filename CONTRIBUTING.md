# Contributing to Float AI

Thank you for contributing to Float AI.

The project follows a simple issue-based workflow so features can be developed independently and reviewed before being merged.

## Development Workflow

```text
Issue
  ↓
Assign yourself
  ↓
Create branch
  ↓
Implement feature
  ↓
Test locally
  ↓
Open Pull Request
  ↓
Code Review
  ↓
Changes if required
  ↓
Approval
  ↓
Merge
