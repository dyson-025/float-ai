# Roadmap

Float AI will be developed incrementally, starting with a small functional MVP and expanding into a polished desktop AI assistant.

## Phase 1 — Foundation

- [ ] Initialize Tauri + React desktop application
- [ ] Initialize FastAPI backend
- [ ] Establish project architecture
- [ ] Configure development environment
- [ ] Add basic CI
- [ ] Establish testing setup

## Phase 2 — MVP

- [ ] Floating desktop bubble
- [ ] Open/close assistant window
- [ ] Basic AI chat
- [ ] Backend AI integration
- [ ] Clipboard integration
- [ ] Global keyboard shortcut
- [ ] Loading and error states

## Phase 3 — AI Actions

- [ ] Improve English
- [ ] Grammar correction
- [ ] Translation
- [ ] Summarization
- [ ] Explain selected text
- [ ] Generate better responses
- [ ] Custom AI actions

## Phase 4 — Product Features

- [ ] User authentication
- [ ] Conversation history
- [ ] User preferences
- [ ] Custom prompts
- [ ] Theme support
- [ ] Configurable keyboard shortcuts
- [ ] Usage limits and management

## Phase 5 — Polish & Reliability

- [ ] Improve performance
- [ ] Improve error handling
- [ ] Add comprehensive tests
- [ ] Security review
- [ ] Cross-platform testing
- [ ] Application packaging
- [ ] Release process

## Future Ideas

These features are not part of the initial scope and may be considered later:

- [ ] Voice input
- [ ] Multiple AI providers
- [ ] AI model selection
- [ ] Streaming responses
- [ ] Usage analytics
- [ ] Plugin/extension system
- [ ] Additional desktop integrations

## Development Approach

Features should be implemented incrementally through GitHub Issues and Pull Requests.

A roadmap item does not need to be implemented in the exact order shown above. Priorities may change based on technical requirements, user feedback, and project progress.

The roadmap should be updated as the project evolves.
